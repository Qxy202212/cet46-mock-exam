# Design Plan — 四六级模考原型 v1.0

## 1. Subject

- 产品：WPS 教学平台 · 模考试室 · 英语四级演示卷
- 受众：考生（作答/看分）、教师（预览卷面）；PC 浏览器
- 本文件/首批页面要完成的单一任务：入口、试卷详情、成绩，以及考场六题型各一屏（与 HTML 单题模式一致）
- 假设与待确认：视觉跟现有模考试室（蓝顶栏 `#2B7DE9`、主色 `#3F80F4`），不套 Ant Design 深色侧栏

## 2. Tone

- surface: b_end
- 气质：utilitarian-enterprise（考场工具密度，不是消费 App）
- 参考气质：教学考试客户端 / 克制后台详情，禁止 SaaS 营销落地页

## 3. Token

相对 DESIGN B 端轨微调：主色与顶栏跟现网模考试室，不用默认 `#1677FF` / `#001529` 侧栏。

### Color

- header: `#2B7DE9`（考场/入口顶栏）
- primary: `#3F80F4`
- page_bg: `#F2F3F5`
- surface: `#FFFFFF`
- border: `#E8E8E8` / `#E6E6E6`
- text_primary: `#333333`
- text_secondary: `#888888` / `#999999`
- danger: `#F54A45`
- warn: `#E86B3A`
- time: `#22A45A`
- sheet_submit: `#F54A45`
- table_header_bg: `#FAFAFA`
- tag_weak_bg: `#FFF1EA`

### Typography

- body: PingFang SC 14/22（卷面正文 15/1.9）
- data: SF Mono 12（分值列可选）
- scale: 11 / 12 / 13 / 14 / 15 / 16 / 17 / 22 / 32（总分环中心）

### Spacing / Radius

- spacing_allowed: [4, 8, 12, 16, 24, 32]
- radius: button 6 / card 8 / tag 4 / max 8
- 答题卡题号：圆形 32
- 试卷结构题号：方形 36、圆角 4

- 页型: b_dashboard
- ASCII:

```
┌─────────────────────────────────────────────┐
│ 蓝顶栏  WPS教学平台 | 四六级模考原型入口      │
├─────────────────────────────────────────────┤

│  │01预览│ │02作答│ │03成绩│                   │
```

- regions: page_header, kpi_row（题数/满分/及格，最多 3）, quick_actions（三入口卡 + 六题型入口，非 KPI）

### paper-preview — 试卷详情

- 页型: b_detail_page
- ASCII:

```
┌ 试卷详情                              [x] ┐
│ ┌──────────────┐  ┌ 试卷结构 ───┐     │
│ │ 居中卷名+元信息 │  │ 写作 1格    │     │
│ │ 一、写作       │  │ 听力 2 3    │     │
│ │ 二、听力+选项   │  │ 选词 4–12   │     │
│ │ 三、阅读三节    │  │ …           │     │
│ │ 四、翻译       │  └─────────────┘     │
│ └──────────────┘                        │
└─────────────────────────────────────────┘
```

- regions: page_header, summary_strip, tabs（四大项作卷面分节）, paper_body, struct_nav

### exam-room — 考场·听力（单题分屏）

- 页型: b_detail_page
- ASCII:

```
┌ 蓝顶栏 试卷名 | 邱老师 | 剩余时间 | 退出 ┐
│ ┌ 单题/整卷 | 标记 收藏 ──┐ ┌答题卡──┐ │
│ │ 播放条 + Conversation   │ │听力 1● 2│ │
│ │ Q1 选项 A–D             │ │选词 26–34│ │
│ │ <上一题  下一题>        │ │[提交]  │ │
│ └────────────────────────┘ └───────┘ │
└────────────────────────────────────────┘
```

- regions: exam_topbar, mode_bar, parent_panel, question_block, nav_bar, answer_sheet
- 答题卡六组：写作 17 · 听力 1–2 · 选词 26–34 · 匹配 36–37 · 仔细 46–47 · 翻译 16；当前题圆点描边

### exam-writing / exam-translation — 无分屏主观题

```
┌ 蓝顶栏 …                                          ┐
│ 写作/翻译标题 + 要求/中文原文 │ 答题卡（当前组高亮）│
│ [多行文本框 placeholder]     │ [提交]             │
│ <上一题  下一题>             │                    │
└───────────────────────────────────────────────────┘
```

### exam-cloze — 选词填空（分屏）

```
│ 上：篇章，空格 26 高亮（可填 assistant）          │
│ ── 拖动条 ──                                      │
│ 下：26.  + A–O 词库圆点（一词一空，已占用半透明） │
```

### exam-matching — 信息匹配（分屏）

```
│ 上：A–M 段原文（可复用）                          │
│ 下：36. 题干 + A–M 圆形字母（当前 I 选中）        │
```

### exam-careful — 仔细阅读（分屏）

```
│ 上：Passage One 素食餐厅篇章                      │
│ 下：47. 题干 + A–D 圆点（考生 A，标准 C）         │
```

### score-detail — 成绩详情

- 页型: b_detail_page
- ASCII:

```
┌ ← 成绩详情          试卷详情 | 时间 ┐
│ ┌圆环46/79┐ ┌写8┐┌听5┐┌读21┐┌译12┐ │
│ └─────────┘ └待提升┘                  │
│ 得分详情 表：题号 题目 分值 得分 答案  │
│                         ┌抽屉 仔细阅读┐│
│                         │题目/我的/标准││
│                         │解析         ││
└────────────────────────────────────────┘
```

- regions: page_header, summary_strip（圆环，非四等宽 KPI 墙）, section_cards, data_table, drawer

说明：右侧四张是「写作/听力/阅读/翻译」题型得分，不是运营 KPI；左侧圆环占独立列，避免四等宽仪表盘。

## 5. Signature

- 元素：题号格导航——考场用圆点（已答蓝底），预览用方格（当前蓝描边）
- 落地规则：只出现在答题卡与试卷结构；入口页、成绩表不用题号宫格当装饰

## 6. Differentiation

- 相对 AI 默认 dashboard：六题型页共用考场壳，差异只在母题/子题控件（词库、字母条、音频、文本框），不是六套不同后台皮肤。
