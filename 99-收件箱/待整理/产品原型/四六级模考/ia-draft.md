# IA Draft — 四六级模考原型

> Phase 0 产出。从 brief 推导，禁止套用固定后台页面清单。

## Brief 摘要

- 原文要点：把已落地的四六级 HTML 原型（入口、试卷详情、考场作答、成绩详情）输出为可编辑 Figma 稿；题型含写作、听力、选词填空、信息匹配、仔细阅读、翻译。
- 产品类型：B 端教学平台模考试室（PC 1440），考生作答 + 教师/考生回看。
- 首批范围：入口 / 试卷详情 / 成绩 + 考场六题型（写作、听力、选词、匹配、仔细阅读、翻译）。不做组卷后台、710 分换算、口语。

## 1. 核心实体

| 实体 | 说明 | 来源 |
|------|------|------|
| 试卷 | 《2026年英语四级考试真题一》，满分 79、17 题、及格 48 | 现有 HTML / PRD |
| 题型/部分 | 写作、听力、阅读（选词/匹配/仔细阅读）、翻译 | 四六级卷面 + 演示数据 |
| 子题 | 一空/一问一条作答；母题材料可共享 | 作答页 `*Group` |
| 作答 | 选项字母或主观文本 | 考场 |
| 成绩 | 客观全对全错 + 主观部分分；分项汇总 | 成绩详情金样 46/79 |

## 2. 角色与目标

| 角色 | 主要目标 | 来源 |
|------|----------|------|
| 考生 | 预览卷面、进考场作答、交卷后看分与解析 | 现有三页 + 入口 |
| 教师 | 只读预览试卷结构（演示顶栏为邱老师） | 考场顶栏 / 试卷详情 |

## 3. 关键任务链

### 任务链 #1 预览整卷

```text
[考生/教师] 要 [确认卷面结构与题干] → 需要 [居中卷名+分值元信息、左侧整卷正文、右侧题号格] → 试卷详情（b_detail_page）
```

### 任务链 #2 考场作答（按题型分屏）

```text
[考生] 要 [按题型完成模考] → 需要 [同一套蓝顶栏+答题卡，题干区随题型切换]
  → 写作/翻译：整区文本框（无分屏）
  → 听力/选词/匹配/仔细阅读：上母题材料 + 下子题作答
```

### 任务链 #3 查看成绩

```text
[考生] 要 [知道总分、哪部分弱、每题对错] → 需要 [圆环总分、四大项分卡、得分表、解析抽屉] → 成绩详情（b_detail_page）
```

### 任务链 #4 从入口进入

```text
[使用者] 要 [在三页间切换演示] → 需要 [试卷元信息 + 三张入口卡 + 独立星火整卷页] → 原型入口（b_dashboard）
```

## 推导依据（必填）

页面不是「后台标配八页」，而是四六级模考一条任务链：先看卷、再作答、再看分。入口页只为演示跳转。阅读三节（选词/匹配/仔细阅读）与写/听/译必须各有一帧考场态，因为单题模式的母子分屏与作答控件不同。成绩页仍用四大项（写听读译），不把阅读拆成三张 KPI。
